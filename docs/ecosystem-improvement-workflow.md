# PF Improvement Workflow

The canonical PF improvement lifecycle, intake rules, artifact workflow, and
validation process live in the dedicated repository:

https://github.com/mrturo-pf/pf-improvements/blob/main/workflow.md

Use GitHub Issues for intake and coordination, the `PF Ecosystem Improvements`
Project for operational state, and `pf-improvements` for investigations,
briefs, recommendations, plans, and durable release evidence.
